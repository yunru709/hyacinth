分析以下对话。提取关键信息，输出 JSON 对象格式（不是数组）：

```json
{
  "keywords": [
    {"keyword": "关键词", "weight": 1-3, "source": "user|assistant|tool"}
  ],
  "turns": [
    {
      "summary": "一句话描述这段对话做了什么",
      "keywords": ["本段特有关键词1", "本段特有关键词2"]
    }
  ]
}
```

要求：
- `keywords`：全局关键词 5-15 个，技术术语/文件名/工具名优先，权重 1-3
- `turns`：每个用户→助手完整交互（一问一答）为一个 turn。为每个 turn 提取：
  - `summary`：一句话（不超过 30 字）描述这段对话做了什么，例如"修复了 login 页面的空指针异常"
  - `keywords`：本段对话特有的关键词 3-5 个
- 去除停用词（的、是、在、了、和、等）
- 不要输出 JSON 以外的任何内容
