> 场景：Agent 的 prompt 版本对比（命中 agent-experiment 子技能；本例只展示通用层产物，领域增量从略）。

## Step −1 · 问题陈述与研究地图（节选）

- 问题（唯一）：在同一 50 条仓库修复任务集上，prompt v2 的任务成功率是否比 v1 高至少 10 个百分点？
- 基线出处：内部 prompt v1（commit `a1b2c3`），无公开可比数字，故以 v1 为复现基线。
- 研究地图（节选，完整树见 research-map.md；本实验是多路线决策，故须建树）：

```
[根] 结构化 prompt 能提升仓库修复任务成功率        [开放]
├─ 【本实验】v2 的增益是否显著超过 δ                 [进行中]  指向 exp-2026-042
│   支撑强度：爬过来（单源观察）；最弱假设：增益可能来自任务集偏置
│   反坍缩：兄弟=「增益来自上下文长度」「增益来自工具描述」；反向=v2 在另一任务集失效；旁支=无（理由：同类方法已由基线覆盖，无额外遮蔽枝）
└─ 【路线B】few-shot 示例替代结构化模板              [开放]  预算盒 3M token，未展开
```

## Step 3 · registration.md（冻结版，节选关键字段）

```
实验ID：exp-2026-042 / 版本 v1 / 责任人：xx / 日期：2026-10-10
parent_experiment：无（首轮）
实验类型：验证性
假设 H1：在修复任务集 T50 上，prompt v2 的成功率高于 v1，差值 Δ ≥ 10pp。
竞争假设 H_alt：v2 的增益来自任务集中「多文件改动」子集的偏置，而非 prompt 本身。
指标 M：任务成功率 = 通过评测的任务数 / 50（部分完成按 rubric v1.2 计 0.5）。
基线值 b：0.62（v1，3 种子 × 50 任务，Step 0 测得）
  - 种子级 SE = 0.03（n = 3 种子，σ_seed ≈ 0.052）← 仅作锚点登记
  - 任务级二项 SE = 0.069（n = 50 任务，√(0.62×0.38/50)）
  - **两者样本单位不同，分别注明；判据一律用差值 SE_Δ，不用上面任何一个**
δ = 0.10（来源：产品侧上线门槛「至少 10pp」，外部依据优先）
  - 兜底对照：δ_fallback = 0.2 × σ_unit = 0.2 × √(0.62×0.38) = 0.2 × 0.485 = 0.097 ≤ 0.10 ✓
α = 0.05（单侧）；MDE = 2.49 × SD_Δ/√n = 2.49 × 0.18/√50 = 0.063 ≤ δ ✓
Δ 判据（单侧，α = 0.05）：支持 = Δ̂ − 1.645·SE_Δ > 0.10；否定 = Δ̂ + 1.645·SE_Δ < 0.10（须做边界检验）；不确定 = 其余
IV：prompt 版本 {v1, v2}
CV：模型 gpt-x-2026-09（锁定）、温度 0、工具集 v3、最大步数 30、任务集快照 sha256:9f8e…
混淆处置：服务端非确定性 → 随机化执行顺序 + 按时段区组；缓存 → 实验前清空
随机种子集合：{101, 202, 303}（3 个，低于默认 5，理由：T50 配对设计 SD_Δ 小、任务级 n = 50 已足够，预算已用 9M/12M；证据强度上限为「中」，升级需补到 5 种子）
重复数：50 任务（配对）× 3 种子；依据：由 δ 反解 n ≥ (2.49 × SD_Δ / δ)² = (2.49 × 0.18 / 0.10)² ≈ 21，取 50（pilot 10 任务估 SD_Δ = 0.18）
统计方法：配对 t（差值 Shapiro-Wilk 预检）；**单侧**，原假设 Δ ≤ 0.10（**不是 Δ = 0**）；效应量 d_z（配对）；校正族 = 1 个比较，Holm（α 不变，故 CI 仍取单侧 95%）
停止规则：固定样本量跑满，不做序贯查看
尝试总数 N_trials：2（v1、v2 各一套配置；pilot 的 10 任务运行计入 pilot，不计入）
候选路线与预算盒：路线 A（本实验，结构化 prompt v2）预算盒 12M token；路线 B（few-shot）预算盒 3M，本轮未展开
剪枝判据：路线 B 与路线 A 统一指标 M；剪 B 当且仅当 B 的上置信界 < A 的下置信界；最小展开深度 k = 一轮完整评估（3 种子）
转向记录：pivot 0
资源预算：约 30k token × 50 任务 × 2 版本 × 3 种子 ≈ 9M token，上限 12M
```

> **同一张表里两个 CI 层级不同，必须分别标注**：单方法的区间是**种子级**（跨种子波动，n = 3，宽）；对比差值的区间是**任务级配对**（n = 50，窄）。配对的价值正在于此——单个方法的绝对水平波动大，但同一条任务上 v2−v1 的差值很稳（SD_Δ = 0.18 ≪ σ_unit = 0.485）。**判据只看后者。**
> 判据验算：SE_Δ = SD_Δ/√n = 0.18/√50 = 0.0255；单侧 95% 下界 = 0.16 − 1.645 × 0.0255 = **0.118 > δ = 0.10** → 支持（双侧下界 0.110 亦 > 0.10，保守版同样过线）。

## Step 7 · 结论（报告节选）

- **结论**：支持 H1。差值 +0.16（任务级配对 95%CI [0.11, 0.21]）；判据所要求的**单侧** 95% 下界 = 0.118 > δ = 0.10，且对 H₀: Δ ≤ 0.10 的单侧 p = 0.011 < 0.05（**注意：这个 p 的原假设是 δ，不是 0**）→ 按 Δ 判据判为「支持」。H_alt（任务集偏置）未被本实验排除：「多文件改动」子集未单独分析，列为后续检验。
- **证据强度：弱**（五项判据满足 2 项，未达「中」的 3 项）。升级路径：补第 2 个任务集、种子补到 5、从零复现后重评。
- 威胁效度：外部效度受限（仅 T50 任务集、单一模型）；构造效度：部分完成计 0.5 依赖 rubric；统计结论效度：N_trials = 2，无多重比较膨胀；任务级配对 n = 50（> 8），可用参数检验；种子层仅 3 次，跨种子方差未被判据捕获，列为不确定性来源之一。
- 负结果：v2 在「多文件改动」子层（n = 12）差值 +0.02，Δ = 0 的检验不显著。**此处不得写「v2 在该子层无效」**——未做非优 / TOST 边界检验，正确结论是**不确定**，列为边界条件与 H_alt 的后续入口。

## 本例刻意示范的五个动作

1. 结果表与台账数字由脚本从 `results/` 生成，不手写（SKILL.md §0 第 6 条）。
2. 检查项勾选落盘 `notes.md`，逐项列全（§0 第 7 条），验证性项未省略。
3. 竞争假设 H_alt 与研究地图反坍缩栏在登记时即写入，而非事后补写。
4. 3 种子偏离默认 5 个，理由与证据上限降级同时写明（SKILL.md Step 2）。
5. 结论如实标「弱」并写明升级路径，不把单设置结果外推（reporting.md §2）。
6. **两个层级的 SE 分层标注**（种子级 0.03 / 任务级 0.069 / 差值级 SE_Δ 0.0255），判据只用差值级——不分层就会让 δ 校验落在错误的 n 上（SKILL.md Step 1 口径一致注 1）。
7. 子层负结果**只判「不确定」不判「无效」**——没做边界检验就不许说等效（statistics.md 第 7 节）。
