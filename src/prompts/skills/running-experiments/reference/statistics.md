## 1. 指标先于实验定义

## 2. 两类不确定度
- 单方法的运行波动：报 均值 ± std 或区间（写明语义：std / SE / 95%CI）。
- 方法间差值的不确定度：比较用**差值的 95% CI**（配对时用差值的配对统计量）。
  - 各方法各自 std 大不代表差值不显著，反之亦然。
- 小样本用 t 分布、自由度 n−1 算区间，不要用小样本 std 配 z 值。

## 3. 检验选择（决策流程）
按顺序判定，并把判定依据（含 n 与检验名）写进登记表：

1. 数据结构是**独立**还是**配对 / 区组**？共几组？
2. **配对 / 区组，两组**：对**差值**做 Shapiro-Wilk。满足正态 → 配对 t 检验；不满足 → Wilcoxon 符号秩。
3. **配对 / 区组，多组**：重复测量 ANOVA；不满足假设 → Friedman。
4. **独立，两组**：默认 **Welch t 检验**（不假设等方差）；若正态性不满足 → Mann-Whitney U（检验**随机优势**，不是均值差）。
5. **独立，多组**：单因素 ANOVA；不满足正态 / 方差齐性 → Kruskal-Wallis。
6. **n < 8**：用**置换检验**（permutation test，10000 次）替代上述参数检验；Bootstrap 只用于估 **CI**（配对 / 区组数据用配对 / 分层 Bootstrap）。

> 正态性一律对**各组或差值**做 Shapiro-Wilk；每种检验必须写明它实际检验的原假设，不要把 Mann-Whitney 当作「非正态版 t 检验」。「n ≥ 8」为经验规则，非硬标准。
> **注意与主文档默认值的冲突**：SKILL.md Step 2 默认 ≥5 个种子，即 n = 5 < 8，**恒落入置换检验区间**。而 methods.md 第 6 节定 n 用的是正态近似 z 值。二者不一致属已知近似误差，处置办法：n < 8 时**同时报告**置换检验 p 与 bootstrap CI，并在报告中声明「功效分析用正态近似，分析用置换检验，小样本下 MDE 为近似值」。

## 4. 多重比较
比较多组 / 多指标时做校正（Holm 或 Bonferroni），并在登记表里定义校正族（哪些比较属于同一族）。
- **校正后 α 必须同时改 CI 水平**：α 变小后，CI 界值要用**校正后的 α** 重算（例如 Holm 校正后 α′ = 0.025 → 用 97.5% 单侧界值）。不得出现「CI 用 95%、p 用校正后 α」的混搭——两者会指向不同的结论。

## 5. 效应量与 MDE
- 报效应量（Cohen d / Cliff delta / 相对改进），不只看 p 值。
- 效应量口径必须与检验配对：配对设计报 d_z = mean(差值) / SD(差值)；独立两组报 d_av（合并 SD）。口径写入登记表，避免两者混用。
- 显著性 ≠ 重要性：判据看差值 CI 是否越过 δ，而不只看 p 值；**注意** CI 与 p 必须来自**同一个原假设**（见第 7 节）。

## 6. 序贯与停止规则
- 边跑边看（peeking）会大幅抬高 I 类错误率；「看到显著就停」等于内置 p-hacking 开关。
- 二选一并**预先声明**：(a) 固定样本量跑满；(b) 序贯方法（alpha-spending / 组序检验 / SPRT）。
- 「停止规则」与「分析计划」一起冻结。

## 7. 边界检验（非优 / 等效 / TOST）
**本节是「否定」判据的唯一合法路径。** 上游 §1 明令「不显著 ≠ 等效」：用 H₀: Δ = 0 的检验没有得到显著，只能判**不确定**，不能判否定。要否定 H1（Δ ≥ δ），必须显式检验**带 δ 边界**的原假设。

记 Δ = M_new − b，SE_Δ = 差值的标准误。

| 结论 | 原假设 H₀ | 检验 | 判据（单侧 α = 0.05，界值 1.645） |
| --- | --- | --- | --- |
| **支持** H1 | Δ ≤ δ | 单侧 superiority-by-margin | Δ̂ − 1.645·SE_Δ > δ |
| **否定** H1 | Δ ≥ δ | 单侧 non-superiority | Δ̂ + 1.645·SE_Δ < δ |
| **等效**（更强的主张） | \|Δ\| ≥ δ（两个单侧） | TOST | Δ 的 **90%CI** 完全落入 (−δ, +δ)，即 TOST p < α |
| **不确定** | — | — | 以上均不成立；尤其「Δ = 0 不显著但没做边界检验」 |

**要点**
- **p 的原假设是 δ，不是 0。** 同一份数据按 H₀: Δ = 0 算出的 p 与按 H₀: Δ ≤ δ 算出的 p 是两个不同的量；主文档判据里的 p 一律指后者。
- **CI 与 p 同源**：支持 / 否定都用**单侧 95%** 界值。若改用双侧 95%CI 的上下界作判据，是**保守**版本（更难过线），须在登记表注明。
- **TOST 用的是 90%CI 而不是 95%CI**（α = 0.05 时两个单侧各占 0.05）。拿 95%CI 去套 TOST 是错的。
- **「否定」≠「等效」**：否定只说明「增益不超过 δ」；要主张「两者无实质差异」必须走 TOST（methods.md 第 7 节）。
- 非参数情形：差值用 **Wilcoxon 符号秩**时，边界检验改用**移位原假设**（每个观测减 δ 后再做符号秩检验），不要直接拿 Δ = 0 的 Wilcoxon p 值去套 δ 判据。
- 小样本（n < 8）：用**配对 bootstrap** 取单侧分位数代替 1.645·SE_Δ。

> 反模式：跑完 t 检验看到 p = 0.31 > 0.05，就写「两组无差异 / 方法无效」。这是把「没有证据」当成「证据表明没有」，正确结论是**不确定**，升级路径是本节的非优检验或 TOST。
