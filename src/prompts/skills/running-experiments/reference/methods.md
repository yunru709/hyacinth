## 1. 对照与基线
- 适用：验证「新方法是否优于已有方法」。
- 做法：实验组 vs 对照组，除被检验因素外一切相同。
- 基线体系：dummy（随机 / 多数类 / 恒定输出）、复现实基线、oracle / upper-bound。
- 公平性：等量调参预算（equal tuning budget）——基线不得只用手写默认超参而新方法精调。
- 陷阱：strawman baseline（故意弱化基线）。

## 2. 消融（Ablation）
- 适用：判断某组件是否必要。
- 变体：
  - same-checkpoint（冻结其余部分，仅移除该组件）：测推理期依赖。
  - retrain（移除后重训）：测训练期贡献。
  - leave-one-out（从完整系统移除）vs add-one-in（从最小系统加入）。
- 结论条件于其它组件在场，不能直接外推。
- 陷阱：一次移除多个组件，无法归因。

## 3. 析因设计
- 适用：多因素及其交互作用需同时考察。
- 全因子：列全水平组合。部分因子：因素多时按分辨度取舍。
- 别名 / 混杂（aliasing）与分辨度（resolution）：砍组合会牺牲某些交互的估计，必须写明牺牲了什么。
- 陷阱：用一次一因子（OFAT）扫描代替析因，无法发现交互且效率低。

## 4. 随机化与区组
- 适用：存在顺序效应、批次效应、缓存 / 限流等服务端非确定性。
- 做法：随机执行顺序；按批次 / 硬件 / 时段分区组，组内比较。
- 区组变量应选已知会影响结果的干扰因素；多干扰时用随机区组或拉丁方。
- 与 statistics.md 的配对 / 区组检验打通（配对信息不要丢）。

## 5. 重复与种子
- 种子数由第 6 节功效分析决定，默认不少于 5，写进登记表。
- 必须说明本次 std 捕获的是哪一层方差：初始化随机性只是其中一部分，数据划分、硬件、并发往往更大。
- 多层不确定时同时报多种子 + 多划分（如 5 种子 × 3 划分）。
- 陷阱：只跑一次就下结论；只报最好的种子。

## 6. 功效与 MDE
- 四输入：效应量来源、α（默认 0.05）、power（默认 0.8）、方差 σ。
  - **两个 σ 别混**：**MDE 用 SD_Δ**（差值的标准差，配对设计会把它压小）；**δ 用 σ_unit**（单位级标准差，不随设计变）。MDE 变、δ 不变，配对设计才有意义。
- **单 / 双侧必须与判据对齐**：SKILL.md Step 1 的「支持 / 否定」判据是**单侧**检验，故默认用单侧界值 z_{1−α} = 1.645；若登记表改用双侧判据则换 z_{1−α/2} = 1.96。混用会让 MDE 与判据对不上。默认系数（α = 0.05，power = 0.8）：**单侧 2.49**、**双侧 2.80**。
- 标准流程：pilot / 预实验估效应量与 σ → 定 n。
- **由 δ 反解 n（推荐路径）**——先定靶，再算最少样本量，而不是盲目加重复数：
  - 配对 / 区组：n ≥ (2.49 · SD_Δ / δ)²
  - 独立两组等样本量：n_每组 ≥ 2 · (2.49 · σ_合并 / δ)²
  - 双侧判据时把 2.49 换成 2.80。
  - 算出 n 后**再回代校验 MDE ≤ δ**，两步互为验算。
- **为什么必须这样**：δ 是**固定靶**，MDE 随 n 缩小，所以加大 n 才有效。若 δ 被定义成含 1/√n 的口径（如 k × SE），δ 与 MDE 会同阶缩水、**比值与 n 无关**，加大 n 永远无法让 MDE ≤ δ —— 这是死循环，必须避免（SKILL.md §2）。
- 算力受限无法做功效分析时的回退：如实报告本次实际可达的 MDE / 事后功效，让读者自行判断。

## 7. 等效性与非劣性
- 适用：要证明「改动没有损害」「两法等效」。
- 做法：TOST（双单侧检验）或非劣性检验，预先设定等效边界 Δ。
- 陷阱：用「不显著」断言等效（absence of evidence）。

## 8. 敏感性分析
- 适用：结论是否依赖某超参或假设。
- 做法：在小范围扰动关键参数，看结论是否稳健；记录于敏感性分析记录表。

## 9. 定性 / 案例研究
- 适用：样本极少、成本极高，无法做统计。
- 做法：结构化案例记录 + 多评审；必须标注「不可泛化」。
