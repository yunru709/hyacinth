# 参考 · 反模式速查

> 上游：SKILL.md。复查 / 复盘时加载。

| 反模式 | 表现 | 修正 |
| --- | --- | --- |
| 无基线 | 只报自己方法的绝对数字 | 补同设置、等调参预算的基线 |
| 弱化基线 | 基线用默认超参，新方法精调 | 等量调参预算 |
| 单次定论 | 跑一次就下结论 | 多种子 + 报告方差 |
| 挑种子 | 只报最好那次 | 固定种子集合，报均值与差值 CI |
| 事后假设 | 跑完再改假设 | 预注册 |
| 挑指标 | 换指标凑显著 | 指标预先冻结 |
| 边跑边看 | 看到显著就停 | 预先声明固定 n 或序贯方案 |
| 混淆未控 | 并发 / 缓存 / 时段影响结果 | 随机化 + 区组 |
| 隐藏失败 | 只报成功案例 | 失败与负结果单列 |
| 数据泄漏 | 测试集参与早停 / 选型 | 测试集绝不参与选择 |
| 不显著当等效 | 没测出差异就说没差异（「p>0.05，所以两组一样」） | 判「否定」必须做**边界检验**（非优 / TOST，statistics.md 第 7 节）；否则只能判「不确定」 |
| δ 用 SE 定义 | δ = k × SE（含 1/√n），加大 n 时 δ 与 MDE 同步缩水，MDE ≤ δ 永远达标不了；或反过来靠加大 n 把 δ 调小来凑达标 | δ 是**固定靶**：外部依据优先，无依据取兜底 0.2 × **σ_unit**（单位级 SD，不是 SD_Δ、不是 SE）。不达标就按反解公式加 n，或改配对 / 区组降 SD_Δ |
| δ 锚在 SD_Δ 上 | 一改配对设计 δ 就变小，门槛被悄悄降低 | δ 锚 σ_unit；配对只降 MDE，不降 δ |
| 拿 Δ=0 的 p 值套 δ 判据 | 判据写「CI 越过 δ 且 p<α」，p 却按 H₀: Δ=0 算 | p 的原假设必须是 **δ**；CI 与 p 同源，且校正后 α 要同步改 CI 水平 |
| 两处 SE 混用 | 基线 b 的 SE 按种子算、MDE 按任务算，δ 校验落在错误的 n 上 | b 的 SE 与判据的 SE_Δ 分别注明样本单位（种子 / 任务 / 划分） |
| 只报 p 值 | 不提效应量与 CI | 报效应量 + 差值 CI |
| OFAT 代替析因 | 一次一因子扫描 | 怀疑交互时改用析因设计 |
| 探索当验证 | 从数据里看出规律后当作验证性结论报 | 标「弱 + 需独立验证」，另起验证性实验（parent 指向原实验） |
| 凭记忆填数 | 登记表 / 结果表数字来自对话记忆 | 由脚本从 runs/ 原始文件生成或核对 |
| DFS 死磕 | 一条线深度不封顶，从不重排候选 | 设路线预算盒，盒满重排 frontier |
| BFS 乱换 | 未到可评估叶就换路线 | 设最小展开深度 k，达标才许剪枝 |
| 凭感觉剪枝 | 没有数据就宣布方向已死 | L3 剪枝须数据触发：候选上置信界 < 竞争者下置信界（单线则 < b + δ），且已达最小展开深度 k |
| 未检索下原理性断言 | 凭参数记忆就说「从未被研究 / 原理上不可能」，并据此剪线 | 先过查新闸门（literature.md 第 5 节）；检索不到只能写「据现有知识未见」，不得升级为原理性结论 |
| 查新走过场 | 只查一个别名、或只按时间排序，命中即止 | 别名表每类 ≥ 3；「查最新」与「查最相关」两路并行；再做种子论文滚雪球 |
| 引文当基线 | 直接把论文里的数字当作本实验的 b，不评级不复核 | 外部数字须按 literature.md §6 评级并写出处；E2 及以下只作待验证锚点，b 必须 Step 0 自己跑出来 |
| 迷信权威 | 因「顶会 / 高引 / 大牛」就把外部结论当「走过来」 | 未亲自复现一律「爬过来」，上限 E2；升级只有自己跑这一条路 |
| 不查污染 | 引用 benchmark 数字却不核对其是否被污染 | 查划分脚本、语料截止、撤稿记录；命中 ★ 红旗直降 E0 |
| 语义坍缩 | 只沿最主流那枝推进，从不列兄弟 / 反向 | 每节点强制填反坍缩栏 |
| 只长一枝 | 整棵树只有「证明」分支，从不质疑根命题 | 对「爬过来」或最弱环节点执行向上质疑 |
| 过度质疑 | 连定义 / 公理 / 多路验证的结论都去推翻 | 只质疑「爬过来」或最弱环；`[地基]` 冻结不质疑 |
