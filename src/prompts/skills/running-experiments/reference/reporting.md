## 1. 报告结构
每个结论必须附：证据表 / 图 + 不确定度 + 威胁效度；负结果与失败单列一节。

## 2. 证据强度分级（逐项判定，取最低档）
五项判据：① ≥2 个设置；② ≥5 个种子（不足须在登记表写明理由）；③ 校正后 p<0.05；④ 差值**单侧 95% 下界** > δ；⑤ 从零复现成功。
- 强：五项全部满足。
- 中：满足 ≥3 项。
- 弱：其余。标注「仅观测，不可外推」，不得用于对外结论。
- 种子不足 5 个时证据上限为「中」（SKILL.md Step 2）。
- **探索性实验**（假设来自数据）的结论一律不超过「弱」，必须标注「需独立验证」；升级路径见 SKILL.md 第 3 节实验类型。

> 统计显著 ≠ 强证据。硬指标是**差值单侧 95% 下界是否越过 δ**：p<0.05 但下界 ≤ δ，只能说「有差异」，不能说「有实务意义的差异」。
> 反过来也成立：p ≥ 0.05 **不代表无效**。要判「否定」必须做边界检验（statistics.md 第 7 节），否则一律「不确定」。

## 3. 威胁效度
逐项检查并写入报告：内部效度（因果是否成立）、外部效度（能否泛化）、构造效度（指标是否真的度量了目标概念）、统计结论效度（检验假设是否满足）、生态效度。

## 5. 模板 · 结果表（唯一列定义）
```
| 方法 | 指标(点估计 [95%CI]) | 对比差值 [95%CI] | 效应量 | 重复(种子/划分) | 检验与校正 | 成本 | 证据强度 | 备注 |
| ---- | -------------------- | ---------------- | ------ | --------------- | ---------- | ---- | -------- | ---- |
```
> 比较类结论必须有「对比差值 [95%CI]」列；全文其他位置引用结果表时，以本节列为准。
> **「检验与校正」列必须写明**：检验名 + **单侧 / 双侧** + **原假设（Δ vs δ，不是 vs 0）** + 校正方法与校正族。缺任一项视为未报告。
> CI 的水平须与判据一致（判据为单侧时默认报单侧 95%，并注明；若报双侧 95% 须注明为保守版本）。
> **效应量口径**：配对设计用 d_z = mean(差值) / SD(差值)；独立样本用 d_av = 均值差 / 两组平均 SD。登记表须指定其一，不得混用。
> 结果表数字由 `analysis/` 脚本从 `results/` 生成，手写即违规（SKILL.md §0 第 6 条）。

## 8. 图表规范
- 误差棒必须写明语义（std / SE / 95%CI），并标注样本数。
- 避免只用柱状图掩盖分布：补 box / violin / strip。
- 坐标轴标注单位，必要时用对数尺度；配色使用色盲安全色板（如 Okabe-Ito），或经色盲模拟工具验证；不以颜色为唯一编码（辅以形状 / 线型 / 标注）。
- 图表底层数据必须留档，可追溯到 runs/<实验ID>/results/。
