# 参考 · 文献检索与查新

> 上游：SKILL.md Step −1（立题、建树与定位）。**触发**：立题时**强制**；写下任何「原理性 / 首创性」断言前**强制**；L3 剪枝理由涉及「这类方法不行」时**强制**。本文件规定**怎么查、查到什么程度算够、查不到怎么处理**；它不存结论数字（数字归 `experiments-ledger.md` 与 `runs/`）。

## 1. 为什么必须有这一节

- 与 §1「不显著 ≠ 等效」同构：统计上「无证据 ≠ 反证据」，文献上「**未检索到 ≠ 无先例**」。
- LLM 的参数知识有**截止日期**且**压缩有损**。「我没检索到 X」实际断言的是「我的参数里没有 X」——这是不可证伪的伪命题。
- 两类真实后果：① 重复造轮子；② 更隐蔽也更贵——把「自己没找到」包装成「**原理上不可能 / 无法补上**」，据此把一条其实可行的路线按 L3 剪掉。**剪枝不可逆，这条错误的代价最高**。

## 2. 能力探测（先做，决定走哪条路）

不要假设自己有什么工具。按下表自上而下探测，命中即停（可并行取并集）：

| Tier | 能力 | 探测方式 | 走哪节 | 能做到的上限 |
| --- | --- | --- | --- | --- |
| **T0** | **无任何出网能力** | 用 curl / urllib / fetch 试一次任意公网地址，失败 | §6 降级 | 只能靠参数知识；**禁止**任何「原理性 / 首创」断言 |
| **T1** | 能发 HTTP 请求（curl / urllib / requests / fetch / wget） | 上一步成功 | §3 | 直连学术 API，查新查全都可行 |
| **T2** | 有网页抓取（WebFetch / headless browser） | 能取回某网页正文 | §3 + §4 | 补 T1 拿不到的页面（实验室主页、会议 proceedings） |
| **T3** | 有网络搜索工具 | 能拿到检索结果列表 | §4 → 回 §3 验证 | 自然语言查新，起手最快 |
| **T4** | 有语义检索 API（Exa / Tavily / Perplexity / Elicit / Consensus …） | 有对应 key 或工具 | §4 → 回 §3 验证 | 召回质量最好 |

> 多个 Tier 同时具备：并行取**并集**，再用 T1 的 API 结果**交叉验证**——语义检索容易给出看似相关、实则不存在条目，必须回 DOI / arXiv ID 核实。

## 3. T1 · 直连学术 API（含已实测配方）

| 源 | 端点 | 认证 | 限速 | 最适合 |
| --- | --- | --- | --- | --- |
| **arXiv** | `http://export.arxiv.org/api/query?search_query=<q>&start=0&max_results=N&sortBy=submittedDate&sortOrder=descending` | 无 | **1 req / 3 s**；批量元数据走 OAI-PMH `oaipmh.arxiv.org/oai` | **查最新**（AI / CS / 物理预印本）；返回 Atom XML |
| **OpenAlex** | `https://api.openalex.org/works?filter=title_and_abstract.search:<q>,from_publication_date:YYYY-MM-DD&per-page=N&mailto=<you>` | 免费 key（2026 起推行，$1/天额度；无 key 亦可用但限额更低） | 礼貌池加 `mailto=` | **查全**（2.4 亿+ works，含引用图） |
| **Semantic Scholar** | `https://api.semanticscholar.org/graph/v1/paper/search?query=<q>&fields=title,year,citationCount,externalIds&limit=N` | **免费 key，必需**（`x-api-key` 头） | 有 key 约 1 RPS 独享；**匿名共享池实测稳定 429** | 引用遍历、`/recommendations`、SPECTER2 向量聚类 |
| **Crossref** | `https://api.crossref.org/works?query=<q>&rows=N&mailto=<you>` | 无 | 礼貌池加 `mailto=` | **DOI 与出版信息校验**（不做语义检索） |
| **CORE / Unpaywall** | `core.ac.uk` / `api.unpaywall.org` | CORE 需免费 key；Unpaywall 需 `email=` | — | 找合法 OA 全文 |
| **HuggingFace** | `https://huggingface.co/api/daily_papers?limit=N` | 无 | 宽松 | 社区**热度**信号（不是学术相关性） |
| **领域补充** | DBLP（CS 书目，无需认证）／Europe PMC（生物医学）／AMiner（中文圈） | 视源而定 | — | 覆盖上表的盲区 |

**五个必备动作**
1. **拆词**：`(方法 / 机制词) × (任务 / 对象词) × (指标词)`，三类各出词再组合。
2. **扩别名**：每类至少 3 个别名——缩写、上位词、社区黑话。例：「无反向传播」= backpropagation-free / local learning / forward-only / feedback alignment / predictive coding / zeroth-order。**只查一个名字会漏掉整个子领域**（实测：不同别名的结果集几乎不重叠）。
3. **两路并行**：**查最新**（arXiv，按 `submittedDate` 倒序，可加 `cat:cs.LG AND` 限定分类）+ **查最相关**（OpenAlex，默认相关度排序）。只按时间排会得到噪声，只按相关度排会得到老论文。
4. **滚雪球**：定位 1–3 篇种子论文 → OpenAlex `filter=cites:<W-id>,from_publication_date:...`（前向）与 `references`（后向）各走一层。这一步召回率通常**高于**关键词检索。
5. **定窗口**：明确「查新窗口」（默认近 24 个月）并写进产出。

## 4. T3 / T4 · 自然语言检索路径

1. 用**问题本身**（而非关键词串）去搜，要求返回**标题 + 年份 + 出处**。
2. **必须回 §3 验证**：把命中条目拿 DOI / arXiv ID 到 Crossref / arXiv 核一遍，**不存在即丢弃**（语义检索会编造条目）。
3. 用命中论文**标题里的术语**反哺别名表，重跑一遍 §3。

## 5. 查新闸门（核心）

立题完成前必须给出三选一判定，写入 `runs/<实验ID>/literature.md`：

| 判定 | 条件 | 处置 |
| --- | --- | --- |
| **已被做过** | 存在同问题、同方法、同量级的已有工作 | 改为**复现对齐**（先复现，再谈改进）；或明确差异化维度后重立题 |
| **部分重叠** | 问题相同但设置 / 规模 / 指标不同 | 写明**可比与不可比之处**；重叠部分作为基线锚点 |
| **空白（暂定）** | 三路检索 + 滚雪球后仍无命中 | 允许立题，但结论**必须带时间戳与检索式**，且**不得**升级为「原理上不可能」 |

> **红线**：未通过闸门，禁止写下「原理上不可能 / 无法补上 / 前所未有 / 首次提出」类断言。这条红线**独立于统计判据**——统计上再干净的自证，也证明不了文献空白。
>
> **与 L3 剪枝的关系**：剪枝判据本身是**相对**判断（候选上界 vs 竞争者下界），与文献无关；但剪枝理由若写成「这类方法原理上不行」，**必须**先过闸门，否则属凭感觉剪枝（见 anti-patterns.md）。
>
> **命中条目须逐个评级（§6）后再引用**：E2 及以下只作线索与 δ 依据，**不得直接充当本实验的基线数字**——b 必须按 Step 0 自己跑出来。

## 6. 外部信息评级（引用任何外部数字前必做）

**为什么单列**：论文是**声称**，不是数据。引用链只证明「有人说」，不证明「成立」；学术不端（测试集污染、弱化基线、挑种子、伪造数据、掠夺性发表）确实存在。**默认不信任，按级取用。**

### 6.1 评级 En

| 级 | 名称 | 达标条件 | 允许用途 | 禁止用途 |
| --- | --- | --- | --- | --- |
| **E0** | 未核实 | 仅标题 / 摘要命中；或来自语义检索**未回验** DOI / arXiv ID | 扩别名、提示「有这个方向」 | 不得入结论、不得作 δ 依据、不得作基线锚点 |
| **E1** | 已核存在 + 读过结论 | ID 已核验（Crossref / arXiv），且读过摘要与结论段 | 建树、列竞争假设 H_alt、定研究方向 | 不得作 δ 外部依据、不得作基线数字 |
| **E2** | 原文数字可定位 | 关键数字能定位到**具体表 / 图 / 章节**，且已判定其设置与本任务**可比** | 可作 δ 的**外部依据**（须写出处 + 可比性判断）；可作**待验证**的基线锚点 | **不得**直接充当本实验判据里的 b |
| **E3** | **亲自复现** | **自己跑过**该论文的方法 / 复现其基线，得到同量级数字（落 `runs/`） | 可作基线锚点 b、可作对比结论、可标「走过来」 | — |

> **封顶规则（硬）**：**未亲自跑过 ⇒ 上限 E2 ⇒ 在 `research-map.md` 里一律只能标「爬过来」**。论文的权威性、作者、期刊、引用数**都不构成升级理由**——`cited_by_count` 只说明「被引多」，不说明「可信」。
>
> **升级路径**：E0→E1 回验 ID；E1→E2 把数字定位到表 / 章节；E2→E3 **只有一条路：自己跑**。

### 6.2 造假 / 污染红旗（与评级正交，独立降级）

命中任一红旗 → **降一级**；命中 ★ 类 → **直降 E0 且禁止作任何数字依据**，并在 `literature.md` 记录。

| 红旗 | 表现 | 怎么查 |
| --- | --- | --- |
| ★ **测试集污染** | train / test 有重叠；benchmark 数据进入预训练语料；划分方式未说明或不可复现 | 核对其划分脚本与时间；查该模型的训练语料截止日期；自己要用该 benchmark 时做 **n-gram / 哈希重叠检测** |
| ★ **数字不可定位** | 摘要数字在正文表格里找不到；正文与摘要不一致 | 要求给出「表 X / 章节 Y」；给不出即 **E1 封顶** |
| **基线弱化** | 对比基线用默认超参，自己的方法精调；调参预算不对等 | 看其超参搜索说明；不对等则其对比结论不可引 |
| **无方差** | 只报单点数字，无 seed / 无 CI / 无重复说明 | 无方差 ⇒ 其 Δ 不可引为效应量 |
| **不可复现** | 无代码 / 无权重 / 无超参 / 无种子 / 数据不公开 | 有代码就跑一次（升 E3 的唯一路径）；无代码则信任上限 E1 |
| **口径含糊** | 未说明是 val 还是 test、指标定义（top-1？哪个子集）、参数量 / 算力 | 口径不清 ⇒ 可比性判定不成立 ⇒ 降一级 |
| **异常理想** | 曲线过平滑、错误率不现实、处处显著 | 对照同领域常识；存疑即降级 |
| **来源可疑** | 掠夺性期刊 / 非同行评议且无代码 / 有撤稿或关注记录 | 查 Crossref 的 `update-to` / relation 字段与撤稿库 |

### 6.3 引用时的写法

- 正文与台账引用外部数字**必须带级**：`[E2] XXX 报 89.0（表 3，CIFAR-10 test）`。
- 同一主张有多个来源时**取最低级**，不取最高级（与 reporting.md §2「逐项判定，取最低档」同源）。
- 标「爬过来」的外部节点**不得**作为向下建子节点的唯一地基；要建，先加固（自己复现），或按 research-map.md 走向上质疑。

### 6.4 与「走过来 / 爬过来」的分工（**不可互相替换**）

| | **En** | **走过来 / 爬过来** |
| --- | --- | --- |
| 标谁 | **外部文献条目**（一条引用） | **研究地图节点**（一个命题，可来自文献**或自己的实验**） |
| 回答 | 这条信息**可信到什么程度、能拿来干什么** | 这个节点**能不能承重**、可否在其上建子节点 |
| 写在哪 | `runs/<实验ID>/literature.md` 的条目表 | `research-map.md` 的节点 |
| 粒度 | 4 档 | 2 档 |

- **对象集不同，故不可合并**：自己实验的结论只有走过来 / 爬过来，**没有 En**；外部文献两个都标。
- **映射单向**：E3 → 走过来；E0–E2 → 爬过来。**不得反推**——见「爬过来」推不出它是 E0、E1 还是 E2。
- **节点写法**：主类 + 可选细档，如 `爬过来（E2）`、`爬过来（本组一次实验）`、`走过来（E3 已复现）`。

## 7. T0 降级（无出网能力）

- 允许继续做实验，但 `literature.md` 必须写明「**未挂检索，依赖参数知识，截止日期未知**」。
- 所有 novelty 表述降级为「据现有知识未见」；**禁止**任何「原理性 / 首创」断言。
- 报告的**外部效度**一栏必须写明此限制，证据强度上限降一级。
- 一旦恢复出网能力，**回补**本节并重新判定闸门。

## 8. 落盘模板

`runs/<实验ID>/literature.md`：

```
检索时间 / 检索者 / 出网能力 Tier
研究问题（一句话）
查询式：别名表（方法 × 任务 × 指标）+ 三路实际请求 + 查新窗口
种子论文（≤3）+ 滚雪球结果
闸门判定：已被做过 / 部分重叠 / 空白（暂定）
关键条目评级：每条 [E0-E3] + 数字出处（表/章节）+ 命中的红旗 + 升级到 E3 所需的复现动作
对本题的影响：基线锚点 / δ 的外部依据出处 / 需否改题
检索盲区：语种、数据库、可能遗漏的别名
```

> δ 的外部依据（§2）优先取自**文献效应量**，此处必须写明出处；取不到才用兜底值。

## 9. 实测坑（照做可省一轮）

| 坑 | 实测表现 | 修正 |
| --- | --- | --- |
| OpenAlex 按日期倒序 | `search=<q>&sort=publication_date:desc` 返回**完全无关**条目，且混入 **2027–2029 未来日期**脏数据 | 改用 `filter=title_and_abstract.search:<q>` + 默认相关度排序，并加 `from_publication_date` 过滤 |
| Semantic Scholar 匿名池 | 连续 4 次指数退避仍 **429** | 申请免费 key，走 `x-api-key` 头 |
| arXiv 限速 | 连续请求被拒 | 间隔 ≥ 3 s；批量走 OAI-PMH |
| 只查一个别名 | 「backpropagation-free」与「local learning」返回几乎不重叠的结果集 | 别名表每类 ≥ 3 个 |
| 语义检索幻觉 | 返回看似相关、DOI 不存在的条目 | 一律回 Crossref / arXiv 核 ID |
| 证书错误 | 某些 Python 环境报 `SSL: CERTIFICATE_VERIFY_FAILED` | 换 `curl` 或补证书；**不是** API 故障 |
| 语种盲区 | 只查英文别名 | 若领域有中文 / 其他语种主战场需补查（中文库多无开放 API，退 T2 / T3） |
| 命中率低就下结论 | 检索不到就宣布「该领域空白」 | 先怀疑**别名与检索式**，再怀疑领域；盲区要写进产出 |
