## 2. 目录与追踪约定
```
runs/<实验ID>/
  registration.md  # 已冻结的实验登记表（Step 3 落盘，之后只读）
  config.json      # 本次全部参数
  cmd.txt          # 复现命令
  logs/            # 原始日志
  results/         # 原始结果与图表（数据留档）
  analysis/        # 分析脚本与中间表（Step 6 落盘；结果表数字由此生成）
  notes.md         # 观察、异常、偏离记录；每步全局检查项勾选结果
```
- 追踪工具（如 MLflow / W&B / Sacred）+ 配置管理（如 Hydra）。
- 绑定：一个结果 ↔ 一个 commit ↔ 一条追踪记录 ↔ 一份 config。
- **跨实验台账**：项目根维护 `experiments-ledger.md`，每行一个实验：`实验ID / 实验类型（探索·验证）/ 问题 / 假设 / 结论 / 证据强度 / 状态（进行中·支持·否定·不确定·作废·已剪枝）/ N_trials / parent_experiment / pivot（转向次数·理由·剪枝理由）`。
  - **写入口径**：数值列（差值 CI、效应量、p、种子数、N_trials）**只由脚本从 `runs/<实验ID>/analysis/` 生成**，人工不得手填；判断列（结论、状态、剪枝理由）由 AI 填写并注明依据的 `registration.md` / `notes.md` 行号。
  - Step 7 完成时必须更新；检索历史结论一律以台账为准，不靠对话记忆。
  - 台账充当搜索的**转置表**：已剪路线必须记录**剪枝理由**（而非只记「死」），以便环境变化后 re-expand（见 SKILL.md §4.2）。前瞻性的 frontier 与谱系不在此，而在 `research-map.md`——本台账只管已跑实验，树只管未跑分支与路线结构。
  - `N_trials` 统计本登记表覆盖的全部运行与配置尝试（含未报告者），用于多重比较与选择偏差的披露。

## 3. 一条命令原则
任何结果都能用一条命令重跑：run.sh / Makefile + config 覆盖 + 输出目录 + 环境锁定文件 + run-id。

## 4. 数据管理与防泄漏
- 划分 train / val / test；声明划分策略（随机 / 时序 / 分组）。
- 防泄漏：时序泄漏、重复样本、同一实体跨划分（分组泄漏）、预处理统计量从测试集算出。
- 测试集绝不参与任何选择，包括早停、超参、模型选择、prompt 选择。
- 数据版本化与许可记录。

## 5. 资源与算力预算
- 预算表：GPU 时 / 费用 / 墙钟 / token。
- 成本核算口径（按什么计费）与超预算停机规则（对接 SKILL.md §4.1）。

## 6. 归档与合规
- artifact 打包（代码 + 配置 + 原始结果 + 分析脚本）、许可证、DOI / Zenodo、容器镜像。
- 伦理与合规：人类被试 / 标注者的审批与知情同意、报酬；PII 与隐私；数据集与模型许可；双重用途与安全披露。
