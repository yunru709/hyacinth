# 子技能 · Agent / 智能体实验规范

> **上游**：本文件从属于主技能 `../SKILL.md`。**通用规范（原则、生命周期、统计、报告、数据卫生、算力预算、追踪）一律以 SKILL.md 及其 `../reference/` 为准**，本文件只补充 Agent 领域**专属**内容。
> **交接契约**：切换时机为 **Step 2 之前**（见 `../SKILL.md` 第 5 节）。进入前须已冻结实验登记表，并把 `../SKILL.md` 第 5 节所列冻结项原文传入（问题、H1、H_alt、指标 M、基线 b 与 δ、MDE、支持/否定/不确定判据、IV、DV、CV、混淆处置、种子集合、停止规则、预算盒）。本文件**不得改写上述任何项**。
> 通用反模式见 `../reference/anti-patterns.md`；跨域实验应先在加载本文件前加载 `../llm-experiment/SKILL.md`。

## 1. Agent 专属变量

| 类别 | 示例 |
| --- | --- |
| IV 自变量 | 规划策略、工具集、记忆机制、prompt 版本、模型、温度、最大步数 |
| DV 因变量 | 任务成功率、平均步数、token 消耗、墙钟延迟、成本、失败类型分布 |
| CV 控制变量 | 模型与版本、工具版本、温度、步数上限、并发度、网络环境 |
| 混淆变量 | 服务端非确定性、API 缓存、限流与重试、时段负载、工具后端状态 |

## 2. 基准与任务集
- 记录任务集来源、版本与**哈希快照**；做污染检查（训练数据是否见过该任务集）。
- **难度分层**：按步数 / 工具数 / 推理深度分层，各层样本量给依据（功效），并**分层报告**。
- 区分**能力型**（能否完成）与**效率型**（花多少步 / 多少钱完成）任务，二者判据不同。
- 多智能体：若角色分配与通信拓扑**不作为 IV**，须固定；作为 IV 时须与依赖变量一起登记并控制其它因子。

## 3. 指标
- 成功率：必须定义「部分完成」如何计分（全对 / 逐步得分 / 人工判定）。
- **截断 / 超时 / 超预算计分规则**：达到最大步数、超时、超预算算失败还是部分完成，须预先写死。
- 成本与延迟：token 计费口径（是否含重试、是否含缓存命中）必须写死。
- 稳定性：报**通过率方差 + 失败类型分布**，不要只报单次成功。
- 回归：新方法在小样本上更好，可能是**回归**（部分任务变差）。必须报「变好 / 变坏」双向计数。
- 聚合：多次运行方差 + 对任务做 bootstrap 的 CI（Agent 版 pass^k）。

## 4. 工具调用失败分类（taxonomy）
预先定义并作为 DV 之一，每一类给出判定规则与计数口径；分类必须**可机械判定**，不依赖主观判断：
- schema / 参数错误、幻觉工具名、超时、权限 / 沙箱拒绝、后端 5xx、结果解析失败、空结果。

## 5. 人工评审协议（当 DV 需人判时）
- rubric 明确到可操作；**双人独立标注**。
- 一致性指标：Cohen κ 或 Krippendorff α，附抽样量与置信区间。
- 盲评；抽样子集及其样本量须先声明。评审者合规与报酬见 `../reference/reproducibility.md` 第 6 节。

## 6. 轨迹日志
- 定义 trajectory schema：`step / action(tool) / args / observation / tokens / latency / status`。
- 要求**可回放**；落盘到 `runs/<实验ID>/trajectory.jsonl`。

## 7. 专属消融对象
- prompt 版本、工具集、记忆、规划策略逐一消融（见 `../reference/methods.md` 第 2 节）。
- 推理期消融的结论**条件于其它组件在场**，不能直接外推。

## 8. 实验隔离（Agent 增量）
- 通用隔离与五项锁定见 `../reference/reproducibility.md`；本节只列 Agent 增量：
- 外部工具一律 mock 或锁定 schema 版本（schema 快照 + 契约测试）。
- sandbox 化以隔离副作用（文件 / 网络 / 进程）。

## 9. 专属陷阱
- **服务端非确定性**：若观察到同输入多次结果不同（采样 / 限流 / 灰度），按 `../reference/methods.md` 第 4 节随机化执行顺序 + 区组处置。
- **缓存**：命中缓存会让「更快」是假的。实验前清缓存或固定缓存状态。
- **限流与重试**：重试会改变成本与延迟统计口径。
- **工具版本漂移**：实验中途工具 / 模型升级会毁掉可比性，须锁定版本。
- **评测集污染**：Agent 常被喂入公开 benchmark，需做泄漏检查。
- **安全**：prompt injection、工具越权、沙箱逃逸、危险动作拦截率，须与任务成功率做权衡表。

## 10. 报告要点
- 结果表遵循 `../reference/reporting.md` 第 5 节（含「对比差值 [95%CI]」列）。
- 必报：成功率、成本、延迟三者的**权衡**，而非单指标最优。
- 负结果：写明「在哪些任务类型上失败」。
