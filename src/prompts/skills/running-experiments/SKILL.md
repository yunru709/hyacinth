# 主 Skill · 通用科研实验规范

> **分工**：本文件是主技能，收纳**所有科研共用**的规范。领域**专属**规范见同目录子技能文件夹 `agent-experiment/`、`llm-experiment/`。
> **定位**：可被 LLM **直接执行**的实验协议——每一步都有门槛、判定标准与中止分支，而非仅供参考的说明文档。

## 0. 使用方式

1. 按 §3 生命周期逐步推进，每步的「产出」必须齐备。
2. 每步结束对照该步的「产出」与 §3 末尾的「全局检查项」自检；未通过不得进入下一步。
3. 命中 §5 领域信号时转入对应子技能；子技能只补充领域专属内容，**不得改写已冻结的假设与判据**。
4. 命中 §4.1 中止分支任一条，立即停止并记录，**不得静默继续**；路线去留按 §4.2 决策。
5. 需要方法细节时按 §6 索引加载参考文件，不在主线展开。
6. 登记表与结果表中的数字必须由脚本从 `runs/` 下原始文件生成或核对，**禁止凭对话记忆填写**。
7. 每步结束把检查项勾选结果落盘到 `runs/<实验ID>/notes.md`，只在对话里声明不算通过。
8. 全局检查项中带 **[验证]** 标记的项，仅验证性实验必填；探索性实验对其写「N/A + 理由」，不得留空。

## 1. 总原则（Tenets）

| 原则 | 含义 | 违反的后果 |
| --- | --- | --- |
| 控制混淆 | 非实验因素保持恒定，或随机化 / 区组化。**不要求一次只动一个因子**（见 methods.md） | 无法归因 |
| 先基线后改进 | 新方法与基线在**同设置、等调参预算**下对比 | 改进不真实 |
| 可证伪假设 + 预先判据 | 跑之前写死假设、指标、成功与否定判据 | HARKing |
| 功效前提下的最小实验量 | 先定要检测的最小效应，再定最少重复数 | 功效不足，把噪声当信号 |
| 可复现优先 | 可复现的普通结果 > 不可复现的惊艳结果 | 结论不可信 |
| 负结果留痕 | 失败、无效、崩溃都要入库 | 幸存者偏差 |
| 预注册 | 假设、指标、判据、停止规则在跑之前冻结 | p-hacking |
| 不显著 ≠ 等效 | 「没检测到差异」不等于「没有差异」；要主张「无效 / 等效」必须走**边界检验**（非优检验 / TOST，见 statistics.md 第 7 节），不得用「Δ=0 不显著」代替 | 把无证据当反证据 |
| 未检索 ≠ 无先例 | 「我没检索到」不等于「不存在」；写下**「原理性 / 首创性」断言前必须先过查新闸门**（literature.md 第 5 节） | 重复造轮子；把「自己没找到」误判为「原理上不行」，据此剪掉可行路线（剪枝不可逆） |

> **红线**：事后改假设、挑随机种子、挑指标、只报成功案例、边跑边看边调判据 —— 一律视为实验无效。

## 2. 术语

- **IV 自变量** / **DV 因变量** / **CV 控制变量** / **混淆变量**（未控制却影响结果者）。
- **操作化定义**：把抽象概念落成**可计算的指标式**。
- **随机化**（两义）：随机**执行顺序**；随机**分配单元**（谁进实验组）。
- **三种复现**：repeatability 同设置重复；reproducibility 同代码同数据可重跑；replicability 换实现 / 换数据仍成立。
- **δ / SESOI**（Smallest Effect Size Of Interest，实务显著性阈值）：**科学与业务上值得关心**的最小差异，**由问题定义**，不由数据反推。取值按来源优先级：
  1. **外部依据**（上线门槛、成本覆盖线、临床意义界值、文献效应量）——**优先**，必须在登记表写明出处。
  2. **兜底值** δ = 0.2 × σ_unit（Cohen 小效应阈值口径），σ_unit = **单位级（单个样本上 M 的）标准差**——它既不含 1/√n，**也不随改用配对 / 区组设计而改变**。无外部依据时使用，并注明「兜底」。
     - 关键：配对 / 区组设计降低的是 **SD_Δ**（从而降 MDE），**不是 δ**。若把 δ 锚在 SD_Δ 上，改一次设计 δ 就变小一次，等于变相降低门槛。
  - **δ 不得用 SE 定义**。SE = σ/√n 含 1/√n，会令 δ 随重复数同步缩水，使「加大 n 使 MDE ≤ δ」永远无法达标（见下条）。**SE 只用于报告不确定度，不用于定 δ**。
- **MDE**（最小可检测效应）：在给定 n、α、power 下本设计**能可靠检出**的最小差异。MDE = (z_{1−α} + z_power) × SE_Δ，随 n 增大而缩小。
- **δ 与 MDE 的关系**：δ 是**固定靶**（不随 n 变），MDE 是**可变尺**（随 n 缩小）——正因为如此，「加大 n」才是有效处方。设计必须满足 **MDE ≤ δ**；不满足时按 methods.md 第 6 节的**反解公式**由 δ 直接算所需 n，而不是盲目加重复数；若预算封顶仍不满足，改配对 / 区组设计降 SD_Δ，或如实报告本次可达 MDE 并下调证据上限。
  - **红线**：不得靠调小 δ、或换用含 1/√n 的口径（如把 δ 定义成 k × SE）来让 MDE ≤ δ「达标」。这属于事后改判据，实验无效。
- **可证伪假设**：形如「在 X 条件下，改变 V 会使指标 M 变化 Δ，且 Δ 超过噪声」的陈述。

## 3. 实验生命周期

**实验类型（先判定，再走流程）**

| 类型 | 适用 | 流程 | 证据强度上限 |
| --- | --- | --- | --- |
| 验证性 | 检验预先写死的假设 | 全流程（Step −1 ~ 8） | 强 |
| 探索性 | 尚无假设，从数据中找规律 | 轻量流程：Step −1 → 2 → 5 → 6（**落盘不可省**，见下） | 弱，必须标注「假设来自数据，需独立验证」 |

- 探索性发现要升级为结论，必须另起一份验证性登记表（`parent_experiment` 指向探索实验）重跑。
- 探索性**跳过** Step 1（假设与判据）、Step 3（冻结）、Step 8（从零复现），但下列三项**不可省**，否则「负结果留痕」原则失效：
  1. 落盘 `runs/<实验ID>/registration.md`，实验类型标「探索性」，假设 / δ / MDE / 判据各栏填「N/A + 理由」（不得留空）；
  2. Step 5 照常落盘 `runs/` 全套与 `notes.md`；
  3. Step 6 后**必须**追加 `experiments-ledger.md` 台账行（实验类型列标「探索」，结论列标「弱 / 需独立验证」）。Step 8 降级为「仅归档原始结果与分析脚本，不做从零复现」。
- **红线**：把探索性结果当作验证性结论报告，等同于事后改假设，实验无效。

### Step −1 · 立题、建树与定位
- 把要回答的**唯一问题**写成一句话。
- **文献检索与查新**（见 §6 索引 `reference/literature.md`，立题前**强制**）：先做**能力探测**选定路径（T0–T4），再走「查最新 + 查最相关 + 滚雪球」三路，落盘 `runs/<实验ID>/literature.md`。据此明确 novelty 与空白；找到**可比基线的数字出处**，判断其设置是否与本任务可比。
- **查新闸门**：给出「已被做过 / 部分重叠 / 空白（暂定）」三选一。**未过闸门不得写「原理上不可能 / 无法补上 / 首次提出」类断言**；判「已被做过」时改为复现对齐或差异化重立题。
- **建树**：以核心问题为根，把前人的结论 / 方法 / 反例整理为**研究地图**（`research-map.md`，见 §6 索引）——每个节点标注支撑强度（**走过来** / **爬过来**）并填**反坍缩栏**；查新命中的已有工作按 literature.md §6 评级：**未亲自复现一律标「爬过来」**，不得凭论文权威性升为「走过来」。再**定位**「本问题位于哪个子节点」（兄弟分支 / 反向操作 / 往下细化），并冻结 `[地基]` 清单。
- 产出：问题陈述 + 相关工作与可比性说明 + `runs/<实验ID>/literature.md`（含查新闸门判定）+ 研究地图与定位说明。

### Step 0 · 基线与环境复现
- 先把基线跑通，做到**一条命令可复现**；记录基线 均值 ± std 作为判据锚点。
- 产出：基线定义（出处 + 复现方式）+ 基线指标与其波动（均值 ± std / SE）。

### Step 1 · 假设与判据
必须产出下表，缺一列不得进入 Step 2：

| 字段 | 要求 |
| --- | --- |
| 假设 H1 | 可证伪的单句 |
| 指标 M | DV 的计算式 |
| 基线值 b | 基线在 M 上的 均值 ± **标准误 SE**（注明该 SE 的**样本单位**：种子 / 任务 / 划分，见下方「口径一致」注） |
| 竞争假设 H_alt | 与 H1 互斥、能解释同一现象的至少一个备择解释（如「增益来自数据量而非方法本身」）；无法列出须写明理由 |
| 实务显著性阈值 δ | 外部依据优先（写明出处）；无外部依据取兜底 δ = 0.2 × **σ_unit**（单位级标准差，**不是** SD_Δ、也不是 SE，见 §2）。低于兜底须写明业务理由 |
| 功效下限 MDE | 由 methods.md 第 6 节得出，且须与判据的**单 / 双侧**一致：判据为单侧时 MDE = (z_{1−α} + z_power)·SE_Δ；双侧时为 (z_{1−α/2} + z_power)·SE_Δ |
| 功效校验 | 在 Step 2 定完重复数后校验 MDE ≤ δ；不满足则按 methods.md 第 6 节**反解公式**由 δ 算 n，或改配对 / 区组降 SD_Δ；预算封顶仍不满足则如实报告可达 MDE 并下调证据上限 |
| 判据（Δ = M_new − b，α 默认 0.05，登记时可改）<br>**先定原假设**：支持性 H₀: Δ ≤ δ；非优性 H₀: Δ ≥ δ | 三类互斥且完备，按序判定（详细口径见 statistics.md 第 7 节）：<br>**支持** = 差值**单侧 95% 下界** (Δ̂ − 1.645·SE_Δ) > δ ⟺ 对 H₀: Δ ≤ δ 的单侧 p < α。<br>**否定** = 差值**单侧 95% 上界** (Δ̂ + 1.645·SE_Δ) < δ ⟺ 对 H₀: Δ ≥ δ 的单侧 p < α。**未经此边界检验不得判否定**。<br>**不确定** = 其余全部情形，含「Δ=0 不显著但没有做边界检验」「CI 跨越 δ」。 |

- 产出：冻结前的假设与判据表。

> **口径一致（三条，登记时逐条核对）**
> 1. **b 的 SE 与判据的 SE_Δ 是两回事**：b 的 SE 只作锚点登记，判据一律用**差值的 SE_Δ**。二者若取自不同样本单位（种子 / 任务 / 划分），必须**分别注明**，不得混用——混用会让 δ 校验与 MDE 落在不同的 n 上。
> 2. **CI 水平与 α 必须同步**：多重比较校正后 α 变小，CI 的界值须用**校正后的 α** 重算，不得出现「CI 用 95%、p 用校正后 α」的混搭。
> 3. **p 的原假设必须是 δ，不是 0**。判据里的 p 若按 H₀: Δ = 0 计算，则它与「CI 是否越过 δ」是两个不同的问题，会把「不显著」误当成「否定」。

### Step 2 · 实验设计
- 选定方法（见 methods.md）。
- 列全 IV / DV / CV，标注混淆变量及处置（恒定 / 随机化 / 区组）。
- 由功效分析（methods.md 第 6 节）决定重复数与种子集合，默认不少于 5 个种子；低于 5 须在登记表写明理由，且证据强度上限降为「中」。
- 校验 MDE ≤ δ（见 §2）；不满足时**按反解公式由 δ 求 n**（methods.md 第 6 节），而不是盲目加重复数；n 已受预算封顶则改配对 / 区组设计降 SD_Δ，或如实报告可达 MDE 并下调证据上限。**不得调小 δ 达标**。
- 产出：设计文档（含随机化与区组方案）。

### Step 3 · 预注册（冻结）
- 填实验登记表（见 reporting.md），冻结：假设、指标、判据、种子集合、分析计划、停止规则、资源预算。
- 冻结后不得修改；必须改时**另起一版**并记录偏离原因；非首轮实验须填 `parent_experiment`。
- 产出：已冻结的实验登记表（含版本号，落盘 `runs/<实验ID>/registration.md`）。

### Step 4 · 环境与可复现准备
- 锁定代码 commit、依赖版本、数据快照、硬件、随机种子。
- 产出：环境锁定清单 + 一条复现命令。

### Step 5 · 执行与记录
- 边跑边记：命令、配置、日志路径、异常、耗时与成本。
- 失败也要入库，附可复现的失败条件。
- 产出：原始运行日志 + runs/<实验ID>/ 目录。

### Step 6 · 数据分析
- 按 statistics.md 选择检验并记录判定依据。
- 报告**不确定度**（单方法波动 + 方法间差值 CI），而非单点数字。
- 产出：分析脚本（落盘 `runs/<实验ID>/analysis/`）+ 结果表（含差值 CI）。

### Step 7 · 报告
- 按 reporting.md 输出：结论 + 证据 + 不确定性 + 威胁效度；**负结果单独成节**。
- 产出：报告正文（含证据强度分级与负结果节）+ 更新 `experiments-ledger.md` 台账（见 reproducibility.md 第 2 节）。

### Step 8 · 复现与归档
- 从零重跑一次关键实验，确认结论稳定；归档代码、配置、原始结果、分析脚本（见 reproducibility.md）。
- 产出：归档包 + 复现结果说明。

**全局检查项**
- [ ] 实验类型（探索 / 验证）已声明？探索性结论未越级外推？
- [ ] 问题唯一？相关工作与基线可比性已说明？
- [ ] 文献查新已做（出网能力 Tier 已声明、三路检索已跑）？查新闸门已判定？未过闸门未写「原理性 / 首创」断言？引用的外部数字已按 literature.md §6 评级（未亲自复现 ≤ E2）？
- [ ] [验证] 假设可证伪？竞争假设 H_alt 已列？支持 / 否定 / 不确定判据、δ 与 MDE 已写死且 MDE ≤ δ？
- [ ] [验证] 判据口径三查：δ **非 SE 口径**（§2）？p 的**原假设是 δ 而非 0**（Step 1 注 3）？**CI 水平与校正后 α 同步**（Step 1 注 2）？
- [ ] [验证] 若判为「否定」，是否**真的做了边界检验**（非优 / TOST），而非拿 Δ=0 的不显著代替？（statistics.md 第 7 节）
- [ ] 基线已一条命令复现，且调参预算与实验组对等？
- [ ] 变量受控、混淆已处理（恒定 / 随机化 / 区组）？
- [ ] [验证] 登记表在跑之前冻结？停止规则已声明？
- [ ] 重复数由功效分析得出？种子集合已固定？低于 5 个种子已写明理由？
- [ ] 候选路线的预算盒与 L3 剪枝判据已声明？未达最小展开深度 k 前未剪枝？（**单线研究**无竞争路线时：预算盒填本实验总预算，L3 判据填单线版「候选上置信界 < b + δ 且已达 k」，**不得留空**）
- [ ] 多路线并行或需做推进 / 剪枝 / 转向决策时：研究地图已建、已定位，每个待决策节点反坍缩栏已填？（纯复现可降级，见 §4.2）
- [ ] 不确定性（含差值 CI）已报告？效度威胁已列？N_trials（尝试总数）已记录？

## 4. 决策分支

三类决策粒度不同，互不替代：单次实验内的统计停止见 statistics.md 第 6 节；**本轮中止**见 §4.1；**整条路线去留**见 §4.2。

### 4.1 本轮中止与失败分支

满足任一条即**停止并记录**，不得静默继续：

| 触发条件 | 处置 |
| --- | --- |
| Step 0 基线无法一条命令复现 | 停止修复；超过 2 轮仍失败则标记「环境阻塞」并上报 |
| 配对差值的种子间 SD > δ（同一指标单位），致 MDE > δ | 停止下结论；加大重复数或改用配对 / 区组设计 |
| 发现 CV 被改动（数据 / 模型 / 超参漂移） | 作废本轮；修正后重跑，登记表另起一版并注明原因 |
| 预算（GPU 时 / 费用 / token）用尽 80%，且差值 CI 宽度 > 2δ 且点估计 < δ/2（「无趋势」的判定口径） | 触发停止规则，按「不确定」归档 |
| 结论与预注册假设相反 | **不得修改假设**；作为负结果记录，写明在何种条件下不成立 |
| 发现数据泄漏或测试集被参与选择 | 作废结论，重建干净划分后重跑 |
| 查新发现本题已被同题工作覆盖，或本轮结论已被已有文献反驳 | 停止按原方案继续；转复现对齐 / 差异化重立题，并在台账记 `pivot` |

### 4.2 路线去留（搜索策略）

**模型（一句话）**：研究 ≈ 在**边搜边生长**的 DAG 上做**价值引导搜索**——树不是给定的，实验本身会暴露未知分支；奖励是**有噪声的代理指标**（需重复采样降噪），边代价未知（需预算盒）。DFS / BFS 是这个搜索的**两个退化失效模式**。统计是**叶评估器**，跨实验台账是**转置表**（避免重探已知死枝）。

**三种失效模式**（先识别，再纠正）：

| 失效 | 表现 | 纠正 |
| --- | --- | --- |
| DFS 死磕 | 一条线深度不封顶，从不重排候选 | 设**路线预算盒**，盒满即重排 frontier |
| BFS 乱换 | 每层浅尝，未到可评估叶就换 | 设**最小展开深度 k**，未达标不许剪枝 |
| 过早剪枝 | 凭「感觉」宣布方向已死 | 剪枝必须**数据触发**（见下） |

**分层（决定用哪档门槛）**：

| 层 | 触发 | 动作 | 门槛 |
| --- | --- | --- | --- |
| L1 实现级 | bug / 环境问题 | 修，登记不变 | 低（§4.1 环境阻塞兜底） |
| L2 方法级 | 实现 / 超参不 work | 换实现 / 加算力，同一登记 | 中，吃同一预算 |
| L3 方向级 | 假设线整体指向否定 | 弃线，按负结果归档，重立问题 | **高，必须数据触发** |

> 「干一半就感觉不行跑路」= 用 L3 的结论去做 L1/L2 的动作（未到可评估叶就换线）。

**剪枝判据（L3，UCB 式）**
- 主判据：候选路线的**指标上置信界 < 竞争路线的最佳点估计**（「它最好的情况都输」）→ 剪。
- **竞争者比较用下置信界**：以候选的**上**置信界对比竞争者的**下**置信界（候选「最好的情况」仍不及竞争者「最差的情况」）→ 剪。用点估计对点估计会把噪声当信号。
- **单线研究**（无竞争路线）：L3 只用相对基线判据——候选上置信界 < b + δ 且已达 k → 剪。
- 可比性前提：多路线须**先统一到同一指标 M** 才可比较；无法统一时退回相对基线判据。
- 最小展开深度 **k**（默认 = 预注册种子数对应的一轮完整评估；可在登记表覆盖，但须写明理由）：未达 k 不得剪。

**预算盒**：每条候选路线预分配预算盒（token / GPU 时 / 墙钟）；盒内不许转向（反 thrash），盒满按上述判据决定。

**沉没成本中性**：已投入**不构成继续的理由**；去留只看**剩余预算下 MDE 与 δ 的关系**。

**反频换与重新展开**：台账 `pivot` 记录转向次数与理由；同一问题**连续转向 ≥ N**（默认 3，可配）→ 触发**重新立题**（回 Step −1），而非再换一条。已剪路线在环境变化（新模型 / 新结果）后可 **re-expand**，故台账须记**剪枝理由**，只记「死」不够。

**研究地图（问题树）**：上文的 frontier 与谱系必须**落到一棵显式的树**（`research-map.md`，见 §6 索引），否则「重排 / 计数 / 剪枝」都无对象。**触发条件**：新研究且存在多条候选路线，或需做推进 / 剪枝 / 转向决策时**强制建树**；纯复现既有工作（单一登记、无路线决策）可降级为台账 + `parent_experiment` 链。树的两条硬约束：
- 每节点标注支撑强度（**走过来** = 严格证明 / 多路独立复现；**爬过来** = 单源 / 类比 / 未复现）——它决定能否在该节点继续下建。
- 每节点**必填反坍缩栏**（兄弟分支 / 反向操作 / 被遮蔽旁支），对抗 LLM 在语义空间的坍缩；**未填不得做推进 / 剪枝 / 质疑决策**。

两种操作：**向下探索**（细化子问题）与**向上质疑**（质疑父命题，仅限「爬过来」或最弱环节点；`[地基]` 冻结不质疑）。详见 reference/research-map.md。

## 5. 领域路由（子技能）

按**正交维度**判定，不按「AI / 软件」二分（AI ⊇ LLM ⊇ Agent，边界会重叠）。

- **对象轴**：模型本身 ←→ 智能体系统
- **方法轴**：训练 / 微调 ←→ 推理 / 测评 ←→ 系统集成

**判定准则**：内容是否**与具体系统、评测集或交互形态耦合**？耦合则下沉子技能，否则留在本通用层。

| 命中信号（任一） | 加载 | 切换时机 |
| --- | --- | --- |
| 仓库 / PR / CI、工具调用、记忆、prompt 版本、任务集、延迟或成本、沙箱 | agent-experiment/ | Step 2 之前 |
| 预训练 / 微调、超参、数据划分、泄漏、对齐 / 安全、吞吐、算力预算 | llm-experiment/ | Step 2 之前 |
| 两者同时命中 | 先 llm-experiment/，再 agent-experiment/，显式声明「跨域实验」 | — |

**交接契约**：切换前必须已冻结登记表，并把以下项**原文**传给子技能：`问题 / 假设 H1 / 竞争假设 H_alt / 指标 M / 基线 b 与 δ / MDE / 支持·否定·不确定判据 / IV / DV / CV / 混淆处置 / 种子集合 / 停止规则 / 预算盒`。子技能**不得改写上述任何项**，只能补充本领域特有的 IV/DV/CV 与陷阱。

> **跨域冲突处理**：跨域实验中，底层模型 / 训练相关的 CV 以 llm-experiment/ 为准，系统 / 工具 / 交互相关的 CV 以 agent-experiment/ 为准；两份 CV 清单取**并集**全部登记，不得取舍。若同一变量两侧定义冲突，以被测 IV 所在层为准；仍无法裁决则上报并冻结两版登记，**不得自行选择**。
