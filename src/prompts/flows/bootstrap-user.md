# Bootstrap Step 3: User Profile (USER.md)

Now let's learn about the user. Chat naturally to understand:

1. **Name/Alias** — How should you address the user?
2. **Background** — Technical background, preferred languages/frameworks, domain knowledge
3. **Collaboration Preferences** — How do they like to work? What's their workflow? Any pet peeves?

When you have enough information, write `{{personaDir}}/USER.md`.

After writing and getting user confirmation, call `complete_flow_step`.
