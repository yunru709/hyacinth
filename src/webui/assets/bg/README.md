# 主题背景图（用户自备素材放这里）

把图片按下面的名字放进本目录，对应主题会自动把它作为最上层背景
（无需改代码，刷新页面即生效；主题自带的压暗遮罩会自动保证文字可读）。

## 文件命名（二选一即可，webp 优先）

| 主题 | 文件名 |
|---|---|
| 夜园（默认） | `hyacinth.webp` / `.jpg` / `.png` |
| 昼园 | `light.webp` / `.jpg` / `.png` |
| 深夜 | `dark.webp` / `.jpg` / `.png` |
| 琉璃 | `glass.webp` / `.jpg` / `.png` |
| 墨韵 | `ink.webp` / `.jpg` / `.png` |
| 雨夜 | `rainy.webp` / `.jpg` / `.png` |

## 通用规格

- **尺寸**：2560×1440 或 1920×1200（16:9 / 16:10 横版），会被 `cover` 裁切铺满
- **大小**：单张 ≤ 2MB（webp 压缩）
- **构图铁律**：中央 60% 区域保持**低对比、低细节**（聊天文字压在上面），
  主体/重点放边缘和角落；不要大面积文字、人脸、高饱和色块
- **明度贴合主题**：深色主题（夜园/深夜/墨韵/雨夜）亮度 ≤ 35%；
  浅色主题（昼园/琉璃）亮度 ≥ 70%

## 各主题想要的画面（详见与助手的对话）

- **夜园**：深夜花园——蓝紫夜色下的风信子花田/球根花园，微光、萤火感，
  右下或左侧可留花丛剪影，中央暗部干净
- **昼园**：清晨柔焦——阳光、露水、虚化花丛，高调低饱和水彩感
- **深夜**：不需要图（纯黑是有意设计）；若一定要，给对比 <3% 的哑光暗纹理
- **琉璃**：大面积 bokeh 光斑 / 晨雾花田，浅色通透
- **墨韵**：宣纸纹理或淡墨山水横卷，带纸的颗粒感
- **雨夜**：雨夜窗户——玻璃雨滴 + 窗外暖黄灯光虚化光斑，蓝灰基调

## 注意

- 全局安装（`hyacinth` 命令）部署时，把图同步到 `dist/webui/assets/bg/`，
  或重新跑一次 `node scripts/copy-webui.cjs`
- 换图后刷新浏览器即可；探测有缓存，新增文件需强刷（Ctrl+F5）
