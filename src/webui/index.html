运行模式

普通模式与陪伴模式在代码里是并列的两套 Router： 普通模式用主上下文与完整工具，陪伴模式切换人格与会话、只保留表达相关能力。 这里选择启动时进入哪一个（也可通过左上角 ✨ 随时切换）。
默认模式
启动时自动进入的模式；也可通过左上角 ✨ 按钮随时切换陪伴模式
启用旁路 Agent
允许 orchestrator 等旁路 Agent 在每轮对话前后注入提示并维护记忆

陪伴模式

以下配置只在陪伴模式生效：角色决定人格与会话目录。 音色与声音管理暂移出设置页，待后端调整后重新接入。
陪伴角色
进入陪伴模式时使用的角色（自动检测 ~/.agent/companion/ 下的人格目录）；陪伴中切换会立即换角色

主题

选择界面配色。主题属于用户偏好，保存在全局配置（~/.agent/config.json 的 ui.theme）， 切换项目目录不会丢失。

代码高亮配色

只影响聊天与预览里的代码块配色，与界面主题分开选择。保存在全局配置 ui.codeTheme；「跟随主题」会随当前主题的明暗自动切换。

系统提示组装器

系统提示不是单个文件，而是由 LayeredContextComposer 按照 context-manifest.json 声明的 Zone → Section 结构，在每轮对话前实时组装而成。每个 Section 可以是 prompt 文件、runtime 数据源、检索结果或条件注入，最终按 priority 排序拼接。
