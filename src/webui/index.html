压缩阶段说明

Phase 1 — ToolOutputTrimmer：规则裁剪旧工具结果、去重、截断过大 tool_call JSON。

Phase 2 — 首次结构化摘要：LLM 将最旧历史压缩为 12 字段结构化摘要。

Phase 3 — 增量摘要更新：基于已有摘要合并新内容，避免重复。

Phase 4 — 保护区规则兜底：超过安全阈值时强制裁剪最近消息。

Phase 5 — 工具消息完整性校验：修复孤立 tool_result / tool_calls。

运行模式

普通模式与陪伴模式在代码里是并列的两套 Router： 普通模式用主上下文与完整工具，陪伴模式切换人格与会话、只保留表达相关能力。 这里选择启动时进入哪一个（也可通过左上角 ✨ 随时切换）。
默认模式
启动时自动进入的模式；也可通过左上角 ✨ 按钮随时切换陪伴模式
启用旁路 Agent
允许 orchestrator 等旁路 Agent 在每轮对话前后注入提示并维护记忆

陪伴角色与声音

以下配置只在陪伴模式生效：角色决定人格与会话目录， 音色决定「用谁的嗓子说话」，声音管理负责音色库（资产）与生成语音（缓存）。
陪伴角色
进入陪伴模式时使用的角色（自动检测 ~/.agent/companion/ 下的人格目录）；陪伴中切换会立即换角色
陪伴音色
该角色说话用的音色（在下方「声音管理」登记与绑定）；换选立即生效
声音管理
音色是你录的真人声音（不可重建，删除前请想清楚）；生成语音是缓存（台词文本仍在），可安全清理
