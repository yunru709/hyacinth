An open source Flash Player emulator

Made to run natively on all modern operating systems and browsers, Ruffle brings Flash content back to life with no extra fuss.

  • Safe to use — Using the guarantees of Rust and WASM, we avoid the security pitfalls Flash was known for.
  • Easy to install — Whether you’re a user or a website owner, we’ve made it as easy as possible to get up and running.
  • Free and open source — Licensed MIT/Apache 2.0, you’re free to use Ruffle however you please!
